# MathWiz 🤖🧮

**Agentic Math AI** — an interactive Python system using multiple AI agents, LLM clients, RAG (Retrieval-Augmented Generation), and custom tools to solve math problems and assist with reasoning. Features include math calculations, modular agent orchestration, retrieval & generation workflows, and extensible tool support.  

**Files & Structure:** `app.py` | `main.py` | `agents.py` | `calculator.py` | `coordinator.py` | `delegator.py` | `llm_clients.py` | `rag_engine.py` | `tools.py` | `data/` | `math_pdfs/`  

**Setup:** `git clone https://github.com/paocent/MathWiz.git && cd MathWiz` → optional virtual env → `pip install -r requirements.txt` → `python app.py` → access via terminal.  

**Contribute:** Add new math agents, improve RAG retrieval, plug in other LLMs, or create a UI. Pull requests welcome!
